# 05: Project Stage Changes, Final Reports, And Decision Resolutions

**What to build:** Objective Stage Changes, Final Founder Reports, and Decision Resolutions appear in the same CEO Office Timeline as task-level items. Goal-level and company-level milestones stay distinct from department reports, and resolved decisions remain visible in chronological history.

**Blocked by:** 01 (Define CEO Office Item Projection Contract), 04 (Project Action-Bearing CEO Office Items)

**Status:** ready-for-agent

- [ ] Objective Stage Changes project as objective-level stage change items, not task-level reports.
- [ ] Final Founder Reports project as company-level final report items.
- [ ] Resolving a decision updates the original pending item and also projects a Decision Resolution item.
- [ ] If a Task Completion Event produces both an Execution Report and a decision request, the Execution Report sorts before the decision request.
- [ ] Stage changes, final reports, and decision resolutions sort into the global Timeline by occurrence time with deterministic tie-breaking.
- [ ] Tests prove stage changes and final reports do not rely on department task-specific display rules.
