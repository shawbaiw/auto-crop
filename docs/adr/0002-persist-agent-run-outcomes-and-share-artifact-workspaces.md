# Persist Agent Run Outcomes And Share Artifact Workspaces

Auto-Crop will persist the actual Agent Run execution facts that explain task outcomes, including Effective Timeout and failure reason, and will expose those facts plus Agent Activity through a Company State Snapshot so dashboard refreshes remain explainable. Task dependencies will be stored as first-class relationships, and dependent validation tasks will run against the upstream task's Artifact Workspace instead of an empty isolated workspace. This replaces the earlier assumption that SSE-only failure details, JSON-only task dependency hints, and per-task isolated workspaces were enough; preserving Proof as the completion gate still matters, but users need durable diagnosis and validation needs access to the product it is validating.
